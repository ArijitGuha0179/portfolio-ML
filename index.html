01

COMPUTER VISION / FEATURE FUSION

PyTorch · MambaVision-T

Adaptive MambaVision

Input-Adaptive Feature Fusion

Letting the input guide how features combine. I extended MambaVision with token-dependent gates across six mixers, bringing state-space and convolutional representations together adaptively.

+0.96 pp82.84% vs. 81.88% accuracy

Additional 5,000-image CIFAR-100 evaluation sample. Mixed gains across evaluations; computational overhead documented.

Read the case study+

My contribution & methods

Added token-dependent gates to combine state-space and convolutional features across six MambaVision-T mixers. The extension adds 5,132 parameters (approximately 0.016%). Identity initialization preserves the pretrained model’s outputs at initialization.

Evaluation

Evaluated on CIFAR-100 and Oxford-IIIT Pet. On an additional 5,000-image CIFAR-100 evaluation sample, accuracy was 82.84% versus 81.88%, a gain of 0.96 percentage points.

Limitations

Gains were mixed across evaluations, and adaptive fusion introduced computational overhead. This result does not establish universal improvement.

Under Prof. Mahesh Mohan M. R.

02

ROBOT AUTONOMY / SIMULATION

MuJoCo · YOLOv8n

CleanQuad

Autonomous Quadruped Litter Collection

Connecting perception to movement. I developed simulated quadruped locomotion and litter detection, then integrated these components into a team-built litter-collection simulation.

0.965 mAP@0.5vs. 0.342 color-based baseline

500 unseen-layout test images. All locomotion and collection results are simulation-based.

Read the case study+

My contribution & methods

Developed Unitree A1 locomotion using trot gait generation, 3-D inverse kinematics, and yaw stabilization. Generated 4,000 auto-labeled images and fine-tuned YOLOv8n for litter detection.

Locomotion & perception evaluation

Passed 20/20 locomotion tests without falls, with reported speed errors below 2%. YOLOv8n achieved 0.965 mAP@0.5 versus a 0.342 color-based baseline on 500 unseen-layout test images.

Team integration

I integrated locomotion and perception components into a team-built simulation. The integrated system collected 7/7 reachable litter items.

Limitations

These are simulation-based results. The collection result covers reachable litter items in the reported test; it is not evidence of real-world deployment or general performance across environments.

Under Prof. Prabhat Kumar Mishra

03

ADVERSARIAL ML / BLACK-BOX EVALUATION

PyTorch · NumPy

One Pixel Attack

Black-Box Adversarial Evaluation

Probing model robustness with a single-pixel constraint. I implemented a gradient-free attack and built evaluation tools to inspect success rates, query counts, and perturbations.

36.46%ResNet-18 · 96 images
47.33%VGG-16 BN · 469 images

Untargeted attack success rates on initially correctly classified CIFAR-10 images; sample sizes differ by model.

Read the case study+

My contribution & methods

Implemented the One Pixel Attack using PyTorch and a custom NumPy differential evolution optimizer, without access to model gradients.

Evaluation

Untargeted success rates were 36.46% on ResNet-18 over 96 initially correctly classified CIFAR-10 images and 47.33% on VGG-16 BN over 469 initially correctly classified images.

Evaluation tooling

Built support for targeted and untargeted attacks, query-count tracking, perturbation visualization, and automated checks of the one-pixel constraint.

Limitations

The results apply to these evaluated samples and model settings. Different sample sizes make a direct model-to-model comparison limited.

Under Prof. Koustav Rudra
